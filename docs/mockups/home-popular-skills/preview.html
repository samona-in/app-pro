Customer home — a “popular skills” section below the services

Three ways to fill the home screen below the category grid, so it scrolls, invites a second look and gets the customer into a booking with one tap. Every option uses the skill’s own icon — copied from its parent service — so the cards read as the service they belong to.

The category grid is illustrative — the live catalogue currently has three active services; the artwork comes from the same public bucket.
